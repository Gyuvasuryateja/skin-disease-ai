# torch/torchvision version note (deployment compatibility):
#   torch 2.14.0 publishes Windows and Linux aarch64 wheels on PyPI but NO
#   Linux x86_64 wheel, so it cannot be installed on Render's x86_64 native
#   Python runtime. torch 2.14.1 (same 2.14 series, patch release) ships

#   Both are pinned to the CPU-only "+cpu" builds from the PyTorch CPU wheel
#   index below: Render's builder would otherwise pull the multi-GB CUDA
#   runtime dependencies (nvidia-*, triton) of PyPI's default Linux wheels.
#   This is a patch-level bump only; the trained model artifact
#   (models/skinvision_efficientnet_b0/best_model.pth) is unchanged and
#   loads identically under 2.14.x.
